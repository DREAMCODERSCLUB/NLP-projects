# 🧠 Basic NLP Projects

This repository contains beginner-friendly Natural Language Processing (NLP) projects using Python. These projects focus on understanding and applying text processing and analysis techniques without the use of large-scale transformer models.

---

## 🚀 Projects Included

| No. | Project                             | Concepts Covered                           |
|-----|-------------------------------------|--------------------------------------------|
| 1   | Text Cleaning & Preprocessing       | Lowercasing, punctuation removal, stopwords |
| 2   | Word Frequency Counter              | Tokenization, word counting, visualization |
| 3   | Basic Sentiment Analysis (Coming)   | Polarity, lexicon-based analysis           |
| ... | More to be added soon               |                                            |

---

## 🛠️ Tools & Libraries Used

- Python 3.11
- `nltk`
- `re`
- `collections`
- `matplotlib` / `wordcloud` (optional)
